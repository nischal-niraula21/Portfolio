# Nischal Niraula Portfolio

Modern dark React/Vite portfolio for `nischal-niraula.com.np`.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Before deployment
1. Replace the `YOUR PHOTO` placeholder in `src/main.jsx` with your real portrait image.
2. Add your CV as `public/Nischal-Niraula-CV.pdf`.
3. Replace the placeholder social links (`href="#"`) with your real profiles.
4. Replace the placeholder phone number.
5. Connect the contact form to your preferred email/form service.

## Deploy
Upload the generated `dist` folder after running `npm run build` to any static host, then point `nischal-niraula.com.np` to that host using the DNS records your hosting provider gives you.
